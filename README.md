🧠 Logistic Regression from Scratch: Gradient Descent Implementation
This project builds a logistic regression classifier from the ground up, without using scikit-learn. It’s designed to reinforce conceptual understanding by manually implementing the full training loop using NumPy.

🔍 Objective
To implement logistic regression for binary classification — predicting a binary label from numerical features — by:
	Deriving the cost function and gradient expressions
	Implementing forward and backward propagation manually
	Updating weights via gradient descent
	Validating against sklearn’s implementation

🚀 What This Project Covers
📊 Data Preparation: Input data normalized and split manually

🏗️ Model Construction:
	Sigmoid activation function
	Binary cross-entropy loss
	Gradient computation for weight and bias updates
🔁 Training Loop: Manual implementation of batch gradient descent
📉 Evaluation: Accuracy and decision boundary plots
✅ Validation: Final model compared with LogisticRegression from scikit-learn

	LogisticRegression.ipynb: Full implementation and walkthrough
